# GOAL
This project aims to create an agentic system that generates finished parametric CAD using only open-source tools. "Parametric" means feature-tree models with editable sketches, constraints and parameters, like Fusion 360 or FreeCAD, not mesh or one-shot geometry output.

The system must also be able to export a URDF for robotics simulation (links, joints, limits, inertials, collision/visual meshes).

GITHUB REPO: https://github.com/Gabriel86-AS/AGENTIC-CAD
